About the collection

Every image starts somewhere.

This is the gallery for vislupus/ai-images. It includes images in the root folder and its subfolders. Text files and video prompts are not loaded.

Behind each image

Open an image to see its prompt, negative prompt, models, seed, and settings when embedded in the original file. Supported formats include ComfyUI, AUTOMATIC1111 / Stable Diffusion, PNG text fields, and JPEG / WebP EXIF data. For unrecognized metadata formats, you can inspect the original text fields.

Prompts and models are read from metadata, never inferred from filenames. If an editor removed the metadata, this gallery cannot recover the original prompt.

Navigation

/ search · ← → previous / next image · Esc close. Click an image to view it at actual size. On a phone, swipe left or right to move between images.

New images and favorites

The gallery checks for new images when you open it. Use the refresh button to check again. Loading more images adds rows below the existing ones. Catalog updates keep the images already on screen in place and add new matches after them. Change the sort order or filters to start a new view. Metadata for new images is read when you open them, then becomes available in search and filters.

Your favorites and theme are saved locally in this browser for this site. They are not synced between browsers or devices. Clearing this site’s browser data removes them. Updating the gallery file on the same site keeps your favorites. No changes are made to the repository.

Publish with GitHub Pages

  1. Save this file as index.html in the root folder of the repository.
  2. On GitHub, open Settings → Pages.
  3. Select Deploy from a branch → main → / (root) and save.

Once published, the gallery is available at vislupus.github.io/ai-images/. GitHub displays the HTML source; GitHub Pages serves it as a website.

This HTML file contains all the code and an initial catalog. Images load from the repository, so the online collection requires an internet connection. If GitHub temporarily limits API requests, the saved catalog remains available. Prompt search covers metadata that has already been read.
